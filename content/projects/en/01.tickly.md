# Presentation

Tickly is a Todoist integration that lets you manage your tasks without leaving Discord.  
To do this, all you need is to add the Tickly Discord bot to your server, or to your account for access from anywhere, connect your Todoist account, and you can manage your tasks.

# Story

Todoist is a popular task management app that I use every day.  
There are many integrations, official or not, to manage your tasks from Microsoft Teams, Slack, etc. But no integration exists for Discord.

In 2026, I started developing a small integration to easily manage my tasks without leaving Discord.  
The goal was to publish an integration on the Todoist website so that it would be useful to everyone.

I wanted to allow simple management of tasks and add features that I think are missing in Todoist, such as the configuration of multiple reminders for the same task or custom recurring reminders.

# Architecture

This project is simply a Discord application serving as an interface to the Todoist API, but it ultimately turned out to be interesting for the design of its software architecture.

I chose an architecture and technologies close to what you find in the industry, with repositories for data access, services to decouple important systems (Todoist SDK interface, OAuth2 authentication to the Todoist API, webhook task retrieval) and a Redis cache.

This is my first real use of Redis in a medium-sized project.  
It is used, for example, for:
- optimizing data access and reducing calls to the Todoist API
- retrieving tasks via webhooks:  
  When a task is created from the bot, it triggers its creation in Todoist, which will notify the bot again via webhook. To avoid infinite loops, we use the Redis cache to store recently modified tasks.
- pub/sub events so communication between services and the bot works smoothly (for example, notifying a connected user only once)

# Feature overview

The bot is translated into **English**, **French**, **German**, **Spanish** and **Polish**.

Here are some of Tickly's main features:
- Create Todoist tasks by command (natural language or form) or by right-clicking a message
- Automatic synchronization of Todoist tasks
- Check upcoming tasks
- (coming soon) Configure bot-related filters for task display
- (coming soon) Notifications and reminders for due tasks, daily, or other configurations
